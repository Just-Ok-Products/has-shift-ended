# Api trenitalia
Deve essere possibile indicare la stazione di arrivo e quella di partenza ma non deve essere visibile di default questa feature.

Considerando uno scarto inserito dall'utente deve essere possibile consigliare un orario di uscita ideale per massimizzare il tempo di presenza ed il tempo per prendere il treno e tornare a casa.
Un esempio è:
- il treno è alle 17:33
- ci impiego 15 minuti per arrivare alla stazione
- il software consiglia di uscire alle 17:18 in grigetto come ultima timbratura di uscita
